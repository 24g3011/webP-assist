📝 課題文

フォームにケーキの注文数を入力して送信を押すと，注文内容を2つのテーブルに記録する．

注文時刻テーブル o_time

  • id：フォームのactionで指定したエンドポイントのメソッド内でUUIDを生成し，それをidにする．#4 の2.4節の手法を使うとよい．

  • 客が見る情報と店員が見る情報は別のページに分けるのが普通だが，単一のページで表示してもよいことにする．

5, ステップアップ

ここでは、実際に課題で要求されているわけではないが、非常に簡単に、より本格的なメニュー表に近づけられる技術を記載する。前の項でcakeshop.htmlに<input type="text" name="count" value="0">を追加した。<input type="text">は「text (=/文字列)を入力できるフィールドを用意する」というような意味の処理である。ここで、目標としている*ステップ1の1-2.htmlページ部分 では、入力される値は「注文数」のことを指すため数字しか受け取る必要が無い。むしろ、注文数の部分に「いち」や漢数字の「一」を入力されると、コントローラー側での処理が非常に難しくなってしまう。そこで、そもそも<input>のtypeにtextではなく、数値を指定して数字だけを入力できるようにした方がよい。

    <div>

ここで、<input>の属性としてさらにmin="0"とvalue="0"を追加している。"min"はその名の通り、最小値として0を設定するということ。この<input>フィールドにおいて、入力される数値が0を下回らないようにしている。"value"はデフォルト値を設定している。

        return price;
    }

    /* 今回は省略のため、各自が実装している他の必要のないselectメソッドはこのコメントアウト部分に記述されていることにする。*/

    public List<Map<String, Object>> select10b() {  // 3.2節で説明されたメソッド

                SELECT
                    o_time.id,
                    o_time.time,
                    cake.name,
                    cake.price,
                    o_qtt.quantity
                FROM o_time       -- テーブル1
                    INNER JOIN o_qtt  -- テーブル2
                    ON o_time.id = o_qtt.time_id
                    INNER JOIN cake   -- テーブル3
                    ON o_qtt.cake_id = cake.id;

5, 新しいメソッドを作る（注文時刻テーブルへの保存）

まずは、注文時刻テーブル o_time に注文のIDを登録するための新しいメソッド orderT を作成する。このテーブルにはIDのみをJava側から渡し、時刻（time）はデータベース側のデフォルト制約によって自動的に現在時刻が設定されるようにする。
過去の資料（3.3節）で紹介されているINSERTの基本形を思い出し、それを応用して実装する。

参考：3.3節で紹介されているコード 
int newcake(String name, int price) {
    String sql = "INSERT INTO cake(name, price) VALUES(?, ?)";
    int count = jdbcTemplate.update(sql, name, price);
    return count;
