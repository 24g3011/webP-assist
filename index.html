2.1節：ケーキ通販Webアプリの作成

📝 課題文

フォームにケーキの注文数を入力して送信を押すと，注文内容を2つのテーブルに記録する．

注文時刻テーブル o_time

  • id：フォームのactionで指定したエンドポイントのメソッド内でUUIDを生成し，それをidにする．#4 の2.4節の手法を使うとよい．
  • time：デフォルト制約を付けているのでJavaで現在時刻を取得する必要はない →2.4節

注文テーブル o_qtt

  • 生成したUUIDおよび，フォームから受け取ったケーキID・個数を登録する．

注文を受けるたびに2つのテーブルをSELECT *で表示しておくと何かと捗る．

注文id，時刻，商品名，単価，個数を売上データとして表示する．

  • 客が見る情報と店員が見る情報は別のページに分けるのが普通だが，単一のページで表示してもよいことにする．
  • 3つのテーブルを結合した結果を表示すればよい．

2, 比較

現状のHTMLページと目標のページを見比べると、現状のNAME, PRICEの列はそのまま名前だけ変えて利用できそうだとわかる。またIDの列は一見必要無いように見えるが、課題の「生成したUUIDおよび，フォームから受け取ったケーキID・個数を登録する．」において"フォームから受け取ったケーキID"というように、フォームからケーキIDを送信したいため、少し調整する必要がある。

例えば、haik.htmlやtask.htmlの<form>において、<input type="hidden" name="id" th:value="${task.id}">のような記述がある。これは「HTML上には表示されないが、一緒にデータを送信できる」部分なため、これをほぼそのまま利用するとよい。

3, テキスト入力欄

続いて、注文数を入力するテキスト欄を追加する。方針としては、「1, HTMLのtableに、テキスト入力欄を置くための新しい列を追加する」「2, 追加した列の要素としてテキスト入力欄を追加する」の2ステップに分ける。

3.1, 列の追加

HTMLのtableに列を追加するのは、単に<thead>内の<th>と、<tbody>内の<td>を増やすだけでいい。

                <thead>
!                   <tr><th>商品</th><th>価格</th><th class="diff-add">注文数</th></tr>
                </thead>
                <tbody>
                    <tr th:each="cake : ${cakeList}">
                        <td style="display: none;"><input type="hidden" name="id" th:value="${cake.id}"></td>
                        <td th:text="${cake.name}"></td>
                        <td th:text="${cake.price}"></td>
+                       <td></td>
                    </tr>
                </tbody>

3.2, テキスト入力欄の追加

新しく追加された「注文数」という列に、テキスト入力欄を追加する。<input>フィールドのtype属性値にtextを指定して<input type="text">とすればよい。

                <tbody>
                    <tr th:each="cake : ${cakeList}">
                        <td style="display: none;"><input type="hidden" name="id" th:value="${cake.id}"></td>
                        <td th:text="${cake.name}"></td>
                        <td th:text="${cake.price}"></td>
!                       <td><input type="text" name="count"></td>
                    </tr>
                </tbody>
4, フォーム化と送信ボタンの用意

ここまで来たら表示部分は送信ボタンを用意するだけ。作成した<table>を<form>で囲い、最後に送信ボタンを追加する。

+       <form action="/order">
            <table border="1">
                <thead>
                    <tr>
                        <th>商品</th>
                        <th>価格</th>
                        <th>注文数</th>
                    </tr>
                </thead>
                <tbody>
                    <tr th:each="cake : ${cakeList}">
                        <td style="display: none;"><input type="hidden" name="id" th:value="${cake.id}"></td>
                        <td th:text="${cake.name}"></td>
                        <td th:text="${cake.price}"></td>
                        <td><input type="text" name="count" value="0"></td>
                    </tr>
                </tbody>
            </table>
+           <input type="submit" value="注文する">
+       </form>
5, ステップアップ（入力制御）

「注文数」には数字しか受け取る必要が無いため、typeにtextではなくnumberを指定し、最小値としてmin="0"を追加する。

!                       <td><input type="number" name="count" value="0" min="0"></td>

💡 データ受け取りの解説（クリックで展開）

cakeshop.htmlの<form>から送信されたデータは、複数行の"count"の値がまとめて渡されるため、Listとして受け取ることで対処します。

@RequestMapping("/order")
    String order(@RequestParam("id") List<Integer> ids, @RequestParam("count") List<Integer> counts) {
        for(int i = 0; i<counts.size(); i++){
            System.out.println(counts.get(i));
        }
        return "redirect:/";
    }
